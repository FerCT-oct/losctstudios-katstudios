# Web de KatLauncher

La página está preparada en `docs/`. Los instaladores están en GitHub Releases.

El propietario debe activar Settings → Pages → Deploy from a branch → main → /docs → Save.

URL prevista: https://ferct-oct.github.io/losctstudios-katstudios/

El instalador de PC 1.7.1 publicado en Releases consulta el manifiesto fijo de GitHub y usa Netlify como respaldo. Las instalaciones anteriores que solamente consultan Netlify necesitan instalar manualmente esta compilación una vez.

No se incluyen herramientas privadas del maestro en las novedades públicas.
