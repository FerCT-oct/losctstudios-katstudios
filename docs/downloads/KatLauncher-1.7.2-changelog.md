# 🎵 KatLauncher 1.7.2 · Kat Music

Tu aventura ahora tiene soundtrack 🐾

- 🎵 Kat Music: escucha YouTube como MP3 temporal dentro de KatLauncher.
- 🎮 Controla la música desde Minecraft: /song URL, /play, /stop y /letkatchose.
- 🐾 Kat elige canciones a partir de tu historial reproducido.
- 🧹 El MP3 se borra al terminar, cambiar de canción o cerrar el launcher. Stop pausa para continuar con Play.
- 🟢 Spotify abre su aplicación oficial con las condiciones de tu cuenta; los controles dependen de su disponibilidad en Windows.
- 🧭 KatLauncher Easy Control: una interfaz más sencilla para encontrar lo que necesitas.
- ✨ Barra superior colapsable y una sorpresa de Kat al pulsar tu avatar en Inicio.
- 📦 Conversión a MP3 incluida: no necesitas instalar FFmpeg por separado.

📥 Actualiza desde KatLauncher o instala la nueva versión desde la web. Reinicia Minecraft para cargar los comandos de KatCraft.

📱 Esta publicación es para PC; Mobile conserva su versión actual. La disponibilidad de vídeos depende de YouTube.
